# Nadzór i delegowanie

Astra 6 prowadzi architekturę, implementację aplikacji, zmiany bezpieczeństwa oraz końcową weryfikację. Luna wykonuje mechaniczne rozpoznanie repozytorium i sprawdzenia. Antigravity otrzymuje proste, ograniczone zadania: katalogi, checklisty, copy, fixture data, ręczne scenariusze QA i formatowanie dokumentacji. Nie otrzymuje sekretów ani danych rzeczywistych kandydatów.

W tej sesji Antigravity / Gemini 3.8 Flash wykonał katalog 8 branż i checklisty integracji. Astra przejrzała i poprawiła nadmierne deklaracje zgodności prawnej oraz niepotwierdzone założenia o API. Model pomocniczy nie stanowi źródła potwierdzenia prawnego lub technicznego.

Przykładowe kolejne zadania Antigravity: ujednolicenie polskich etykiet, rozbudowa syntetycznych fixture dla branż, lista pustych/błędnych stanów UI, instrukcja onboardingu klienta i checklisty QA. Każde zadanie ma listę dozwolonych plików, kryteria akceptacji i wymaga przeglądu Astry. Zadania backlogu wskazują proponowaną ścieżkę wykonania; nie oznaczają uruchomionego delegata.

Nadzór modeli podczas tworzenia produktu jest odrębny od wykonywania pracy HR w produkcji. Tam trwały workflow i jawne polityki sterują narzędziami, a uprawniony człowiek podejmuje decyzje zatrudnienia. Dostępność modelu w T3 nie gwarantuje jego dostępności jako API dla produktu.
